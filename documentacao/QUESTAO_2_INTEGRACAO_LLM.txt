QUESTÃO 2 — INTEGRAÇÃO DE LLM COM FASTAPI NO AMBIENTE LOCAL

A integração foi desenvolvida a partir da API FastAPI já utilizada no Transparência Brasil, sem substituir os serviços de consulta de despesas, estatísticas e coleta de conteúdo Web. O objetivo foi permitir que a aplicação processasse textos com um modelo de linguagem instalado no próprio computador, sem depender de uma API de inteligência artificial hospedada na nuvem.

O modelo escolhido foi o Qwen3-4B-Instruct-2507, disponível no Hugging Face. A implementação utiliza Transformers para carregar o tokenizador e o modelo, PyTorch para realizar a inferência com aceleração CUDA e bitsandbytes para quantizar os pesos em 4 bits. Essa configuração foi planejada para um computador com 16 GB de RAM e uma NVIDIA GeForce RTX 4060 Laptop com aproximadamente 8 GB de memória de vídeo. O limite inicial de entrada foi definido em 2.048 tokens e a geração permite até 512 novos tokens, de modo a controlar o consumo de recursos.

Foi criada a rota POST /processar_texto. Nela, o usuário envia um texto e informa se deseja obter um resumo ou uma explicação. A FastAPI valida a solicitação, encaminha o conteúdo ao serviço local e devolve uma resposta JSON contendo o resultado, a operação realizada, a identificação do modelo e informações sobre a execução. Também foi acrescentada a rota GET /ia/health, que permite verificar a disponibilidade dos arquivos e o estado do modelo sem carregá-lo apenas para consultar sua situação.

O modelo é carregado somente quando uma requisição exige processamento. Após o primeiro carregamento, a mesma instância é reutilizada, evitando a repetição de uma operação custosa. A geração é serializada para impedir que várias solicitações ocupem a GPU simultaneamente. O modelo não é baixado automaticamente pela API: o download inicial ocorre por um script específico, e as chamadas posteriores utilizam exclusivamente os arquivos armazenados no computador, com as opções de carregamento offline habilitadas.

Para completar a integração com a aplicação, foi acrescentada uma página no Streamlit. Ela permite inserir o texto, escolher o tipo de processamento e visualizar a resposta retornada pela FastAPI. Também foram criados um script para diagnóstico da GPU, outro para baixar o modelo do Hugging Face e um teste HTTP que verifica a resposta produzida pela inferência real.

A implementação e os contratos HTTP passaram pelos testes automatizados no ambiente de desenvolvimento, preservando os testes anteriores do TP3. Esses testes não devem ser confundidos com a execução efetiva do modelo: o download dos pesos e a geração real na RTX 4060 foram concluídos e confirmados pelo usuário, com respostas retornadas pela FastAPI e pela interface Streamlit. O procedimento de instalação, os comandos de execução e a verificação offline estão documentados no arquivo GUIA_LLM_LOCAL.md. Assim, o desenvolvimento da integração está concluído em código, e a comprovação adicional de funcionamento com a internet desconectada permanece pendente.
