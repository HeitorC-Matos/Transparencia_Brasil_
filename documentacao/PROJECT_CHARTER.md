# Project Charter - Transparência Brasil

## Projeto

**Transparência Brasil** - aplicação em Streamlit para facilitar a visualização de informações sobre gastos públicos estaduais.

## Relação com a Agenda 2030

O projeto está relacionado ao **ODS 16 - Paz, Justiça e Instituições Eficazes**, principalmente ao tema de instituições transparentes e acesso público à informação.

## Problema

Dados públicos fiscais estão disponíveis em fontes oficiais, mas podem ser difíceis de interpretar por usuários que não estão acostumados com relatórios e sistemas governamentais.

## Objetivo

Apresentar informações de gastos públicos de forma simples, permitindo comparar dados de São Paulo, Goiás e Bahia e consultar conteúdo complementar obtido de páginas públicas na Web.

## Escopo do TP2

- manter a aplicação criada no TP1;
- adicionar filtros e interação na interface;
- coletar conteúdo de páginas Web com Beautiful Soup;
- armazenar a coleta em CSV e TXT;
- apresentar estatísticas simples e nuvem de palavras;
- utilizar cache e estado de sessão do Streamlit;
- permitir upload e download de arquivos CSV;
- preparar o projeto para versionamento com Git e deploy.

## Fora do escopo

Não fazem parte desta etapa sistemas de login, banco de dados, modelos de machine learning ou coleta automática em tempo real.

## Stakeholders

- aluno responsável pelo desenvolvimento;
- professor responsável pela avaliação;
- usuários interessados em consultar informações públicas de maneira simplificada.

## Entregas

- aplicação Streamlit atualizada;
- script de coleta Web;
- arquivos CSV/TXT com conteúdo coletado;
- Project Charter;
- Data Summary Report;
- arquivos necessários para execução e versionamento do projeto.
